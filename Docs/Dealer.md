# 딜러 정비 안내 — 공개 후보 선택 방식

- 정비마다 12장 중 5장을 처음부터 공개합니다.
- 공개된 카드 중 2장을 무료로 선택합니다. 선택하면 즉시 효과가 적용됩니다.
- 추가 선택은 2 → 3 → 4…코인입니다.
- 숨겨진 7장은 원하는 뒷면을 눌러 추가 공개합니다. 공개 비용은 1 → 2 → 3…코인입니다.
- 공개와 선택의 가격은 각각 따로 증가합니다. 공개만 해서는 효과가 적용되지 않으며 무료 선택도 소모하지 않습니다.
- 각 카드 버튼에 현재 가격을 표시합니다. 코인이 부족하면 비활성화됩니다.
- 정비를 떠나면 고르지 않은 카드는 사라집니다. 보관이나 미선택 보상은 없습니다.
- 다음 정비에서 공개 5장, 무료 선택 2회, 두 비용이 초기화됩니다.

효과는 합계 성장·해금, 특정 랭크 추가·제거, 코인 +3, 이번 스테이지 핸드 +1입니다. 이전 선택 때문에 공개된 효과가 사용 불가능해지면 선택 가능한 코인 카드로 바뀝니다. 숨겨진 효과가 사용 불가능해졌다면 공개 시 유효한 효과로 교체합니다.

검증: 딜러 규칙 138개, 기존 핵심 규칙 89개 통과. 실제 UI에서 두 번의 무료 선택과 유료 공개, 지갑 차감 및 가격 독립 표시 확인. 이번 변경의 클리어 확률은 별도로 측정하지 않았습니다.
